# Café Origen – Analítica de ventas

Proyecto para analizar el historial de ventas de Café Origen usando JavaScript (Node.js).

## Estructura
- `src/datos.js`: ventas originales
- `src/analitica.js`: indicadores de ventas calculados con ciclos for...of
- `src/explorar.js`: exploración inicial de los datos
- `src/probar.js`: pruebas de los indicadores con distintas entradas
- `src/verificar.js`: comprueba que las versiones con métodos dan lo mismo que los ciclos
- `bitacora.md`: decisiones y hallazgos

## Uso
    node src\explorar.js
    node src\probar.js
    node src\verificar.js
